## <img src="https://media.giphy.com/media/hvRJCLFzcasrR4ia7z/giphy.gif" width="28"> Overview

**GRAVITY** is not just a store — it's a **digital flagship**. A full front-end commerce experience where **WebGL-rendered backgrounds**, **physics-based smooth scrolling**, and **editorial-grade typography** meet a complete shopping flow: browse → filter → quick-view → wishlist → cart → checkout → rewards.

Every interaction — from the **magnetic custom cursor** to the **cinematic page transitions** — is engineered to feel luxurious, tactile, and alive.

> ⚠️ **Demo Mode** — Mock auth & simulated checkout. Built for portfolios, education & design showcases. See [PRODUCTION_WARNING.md](PRODUCTION_WARNING.md).

## 🚀 Quick Start

**Prerequisites** — Node.js `v18.17+` · npm / yarn / pnpm

```bash
# 1️⃣ Clone
git clone https://github.com/random1619/gravity-commerce.git
cd gravity-commerce

# 2️⃣ Install
npm install

# 3️⃣ Ignite dev server
npm run dev
```

🖤 Open **[http://localhost:3000](http://localhost:3000)** — welcome to GRAVITY.

<details>
<summary><b>📜 Available Scripts</b></summary>
<br/>

| Command | Action |
| :-- | :-- |
| `npm run dev` | Start dev server on port **3000** |
| `npm run build` | Production-optimized build |
| `npm run start` | Serve the production build |
| `npm run lint` | ESLint across TS/TSX |

</details>

## ⚠️ Demo & Security

GRAVITY ships with **active protective measures** — rate limiting (100 req/min/IP), security headers (HSTS, CSP, XSS), input validation & auth-gated routes — **but** runs in **demo mode**:

- 🔸 Mock auth (localStorage, no password hashing)
- 🔸 In-memory data (no database)
- 🔸 Simulated checkout (no payments)
- 🔸 Placeholder student verification

✅ **Perfect for:** portfolios · UI/UX demos · education · design showcases
❌ **Not for:** real transactions · real user data · production business

➡️ Read [PRODUCTION_WARNING.md](PRODUCTION_WARNING.md) — security model, deployment notes & production-readiness (consolidates the former `SECURITY.md` and `DEPLOYMENT.md`).
